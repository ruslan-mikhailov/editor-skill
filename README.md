# Editor Skill

An AI editing skill that cuts clutter, clarifies meaning, and preserves your voice.

Proofread, copyedit, revise, or critique prose without changing its meaning, factual claims, or level of certainty.

## Install

Install the skill from the command line:

```bash
npx skills add ruslan-mikhailov/editor-skill --skill editor
```

The installer prompts you to choose a target agent. Installation is project-local by default. Add `--global` to make the skill available across projects.
