Kubernetes is an open-source container orchestration platform, originally designed at Google and now maintained by the Cloud Native Computing Foundation, that automates the deployment, scaling, and management of containerized applications across a cluster of machines. You describe the desired state of your system in declarative configuration files, such as how many replicas of a service should run, which container images they use, and how they should be exposed on the network, and Kubernetes continuously works to make the actual state match that description. It handles scheduling containers onto nodes based on available resources, restarting containers that fail, rolling out updates gradually, load balancing traffic across healthy instances, and managing configuration and secrets. The core abstractions include Pods (the smallest deployable units, usually one container each), Deployments and StatefulSets for managing groups of pods, and Services for stable networking. Because it abstracts away the underlying machines and works across clouds and on-premises environments, Kubernetes has become the de facto standard for running containerized workloads at scale.
